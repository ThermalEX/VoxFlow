# 新手教程、组件下载与配色主题设计

日期：2026-10-18
状态：设计草稿，待用户确认

## 1. 背景与目的

现在的安装包有 2.8 GB，其中改写模型 2 GB、llama.cpp（CUDA 版）1.2 GB、语音识别模型 230 MB，程序本身不到 200 MB。体积超过 GitHub Releases 单文件 2 GB 的上限，无法在 GitHub 上发布；而且不是每个用户都需要智能编辑，也不是每个用户都有 NVIDIA 显卡。

目标是：**安装包只含程序本体**，模型和运行组件放在网上，由用户在软件里按需下载；第一次打开时用一个新手教程，带用户完成语言、外观、麦克风、组件下载和第一次试用。同时把“配色”做成整体主题，统一浮层和设置界面的颜色。

## 2. 目标

1. 安装包只含程序本体（预计压缩后一两百 MB 以内），可以发布到 GitHub Releases。
2. 语音识别模型、llama.cpp、改写模型都可以在软件里下载：加载列表 → 勾选 → 一键下载，每项有独立进度。
3. 下载源可选：自动 / Hugging Face / 国内镜像，选项醒目。
4. 第一次打开时出现 6 步新手教程，随时可跳过，可在“关于”里重新开始。
5. 外观页新增配色主题：6 个预设 + 自定义；主题统一控制浮层柔光、胶囊柔光和设置界面强调色。
6. “关于”页：版本和作者分两行（已完成），GitHub 与 Hugging Face 链接（已完成，`2b5486b`），右侧加“重新开始教程”按钮。

## 3. 非目标

- 软件自身的自动更新（关于页的更新频道等控件继续保留为禁用的占位）。
- 下载 Hugging Face 以外来源的任意模型；“选择自己的 GGUF 文件”保留，但不做在线搜索。
- 同时下载多个文件（逐个下载，避免抢带宽）。
- 改动语音识别、改写模型本身或训练流程。

## 4. 反目标（做了也算失败的情况）

- 下载过程中界面卡住，或必须保持设置窗口打开才能继续下载。
- 留下半截文件被当成可用模型；未通过校验的文件被选用。
- 用户没同意就自动下载上 GB 的文件（教程里的预选也必须用户点“下载”才开始）。
- 没有语音模型时软件崩溃或只显示难懂的报错。
- 教程强迫用户走完；或跳过后再也找不到入口。
- 配色主题只换了浮层，设置界面还是原来的蓝色，看起来不统一。
- 把录音写入磁盘（下载功能与录音无关，保持现状）。

## 5. 约束

- Windows + Python 3.12 + PySide6；沿用现有设置窗口的组件（`SettingsCard`、`SettingRow`、`SettingsComboBox`、`ToggleSwitch`）、主题（`settings_theme.py`）和双语机制（`i18n.py` 的 `tr()`，所有新文字中英两份）。
- 用户设置存 `QSettings("VoxFlow", "VoxFlow")`。
- 源码运行时仍使用仓库里的 `models/`、`runtime/`、`training/rewrite/runs/`，开发流程不变。
- 测试不访问网络：下载器、清单获取都要可注入。
- 已下载文件必须用 SHA-256 校验。

## 6. 已确定的设计（用户决定）

### 6.1 安装包

只含程序本体：PyInstaller 产物，不含 `models/`、`runtime/llama.cpp/`、`runtime/models/`。`packaging/build.py` 去掉拷贝这三项的步骤；`voxflow.iss` 去掉对应的 `[Files]` 条目。

### 6.2 下载内容与托管

| 组件 | 是否必需 | 来源 |
| --- | --- | --- |
| 语音识别模型 SenseVoice INT8（`model.int8.onnx` 239 MB + `tokens.txt` + `LICENSE`） | 必需，没有它无法录音识别 | Hugging Face `csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`（sherpa-onnx 作者维护，`model.int8.onnx` 与现用文件哈希一致），固定到某个提交 |
| llama.cpp b11596，两个版本由用户选一个：**通用版（Vulkan）**下载 30 MB / 解压 88 MB，支持 NVIDIA / AMD / Intel 显卡；**NVIDIA 加速版（CUDA）**下载 625 MB / 解压 1.2 GB，只支持 NVIDIA | 本地智能编辑必需（二选一） | 用户决定：不打包，在软件里下载，两个版本都提供并注明效果。见 §7.5 |
| 改写模型 GGUF（v4 Q8 1.9 GB 推荐 / v4 Q4 1.2 GB） | 可选 | Hugging Face `ThermalEX/voxflow-rewrite`，固定标签 `v4`（已上传） |

国内镜像：把下载地址的 `huggingface.co` 换成 `hf-mirror.com`，路径不变（已验证两者对 v4 文件都返回 200）。

### 6.3 设置 › 智能编辑：模型管理（草图第 2、3 版）

分上下两块：

**已安装的模型**：列出本机可用的改写模型（现有的发现逻辑），标出“使用中”，每项可“删除”（只能删除软件下载的文件）；保留“选择自己的 GGUF 文件”。

**下载模型**：
1. 顶部单独一行“下载源”，分段按钮：**自动 / Hugging Face / 国内镜像**，下面一行说明“自动：先连 Hugging Face，连不上或太慢就换成国内镜像；国内网络建议直接选国内镜像”。选择保存在设置里。
2. “↻ 加载列表”按钮：读取下载清单（§7.1），列出可下载项，每项前有勾选框；已安装的项标“已安装”且不能勾选。
3. 底部显示“已选 N 项 · 共 X GB”和“下载所选”按钮。
4. 下载时每项一行：进度条、百分比、已下载/总大小、速度、预计剩余时间、“取消”；未轮到的显示“排队中”；底部“总进度”和“全部取消”，并说明“可以关闭设置窗口，下载会在后台继续”。
5. 下载完成并校验通过后，该项进入“已安装”；如果当前没有可用模型，自动选用刚下好的推荐模型。

语音识别模型和 llama.cpp 也出现在这个列表里（标明“必需”），这样教程和设置共用同一套下载界面。

### 6.4 新手教程（草图“整体流程”，用户已认可）

独立窗口，外观与设置窗口一致（跟随颜色模式和配色主题），一步一屏，底部“上一步 / 下一步”，右上角“跳过”。第一次启动时自动出现；完成或跳过后不再自动出现；“关于”页“重新开始教程”可再次打开。

| 步骤 | 内容 |
| --- | --- |
| 1 欢迎 + 语言 | 欢迎语；简体中文 / English / 跟随系统，切换后教程立即换语言 |
| 2 外观 | 颜色模式（跟随系统 / 浅色 / 深色）+ 配色主题色块；旁边实时预览语音浮层 |
| 3 麦克风 | 选择麦克风；对着说话时音量条跳动（只在内存中取音量，不录音、不落盘） |
| 4 下载组件 | 使用 §6.3 的下载界面（精简版）：语音识别模型（必需）、llama.cpp、推荐改写模型默认勾选，用户点“下载”才开始；可以先跳过，之后在设置里下载 |
| 5 动手试一次 | 讲解快捷键（显示用户当前设置的键）、说一句示例话、Enter 输入 / Esc 取消；语音模型没下好时提示“下载完成后即可试用” |
| 6 完成 + 小技巧 | 语音指令、“继续说”、悬停“撤回修改”、托盘常驻 |

### 6.5 配色主题（设置 › 外观）

- 6 个预设 + “自定义”，以色块网格显示（草图名称：晴空蓝、暮紫、青绿、暖橙、樱粉、石墨，可调整）。
- 每个主题是一组颜色：**浮层背景柔光、胶囊柔光、强调色**。强调色用于设置窗口和教程中的开关、主要按钮、选中项、链接、下拉框勾选标记、进度条。
- 用户决定：主题是一个整体，浮层和设置界面统一变色。
- 选“自定义”时显示现有的“背景柔光 / 胶囊柔光”两个颜色选择器，强调色跟随胶囊颜色。
- 颜色模式（浅/深）与配色主题独立，可任意组合。
- 默认主题为“晴空蓝”（即现有的 `#438aee` / `#2766d6`），已有用户自定义过颜色的，迁移为“自定义”并保留原颜色。
- “恢复默认外观”恢复为默认主题。

## 7. 我的设计决定（可以否决）

### 7.1 下载清单放在 Hugging Face

在 `ThermalEX/voxflow-rewrite` 仓库根目录放 `catalog.json`，“加载列表”时读取它；软件内置一份同样内容的副本，读取失败（离线、网络不通）时用内置副本并提示“使用内置列表”。好处：以后上传 v5 并更新清单，已发布的软件不用重新发布就能看到新模型。

每项字段：`id`、`kind`（`asr` / `runtime` / `rewrite`）、中英文标题与说明、版本、是否必需、是否推荐、需要的显存提示，以及文件列表（仓库、固定版本、路径、大小、SHA-256、安装后的相对位置、是否需要解压）。

### 7.2 下载文件放在用户数据目录

安装版的下载内容放在 `%LOCALAPPDATA%\VoxFlow\`（`models\`、`runtime\llama.cpp\`、`runtime\models\`），与程序目录分开，重装或升级软件不用重新下载。源码运行时仍用仓库目录。`paths.py` 增加“数据目录”的概念：源码运行 = 仓库根目录，打包后 = `%LOCALAPPDATA%\VoxFlow`。

### 7.3 下载器行为

- 在后台线程逐个下载，界面通过信号或定时轮询更新进度。
- 先写到 `*.part`，支持断点续传（HTTP Range）；完成后校验 SHA-256，通过才改名为正式文件；需要解压的（llama.cpp zip）解压到临时目录后整体替换。
- “自动”下载源：先请求 Hugging Face，连接失败或前 10 秒平均速度低于 200 KB/s 时切换到镜像并从断点继续。具体阈值由实现者调。
- 取消时删除对应的 `.part`；网络中断时显示“已暂停，可重试”。
- 设置窗口关闭不影响下载；全部完成时托盘气泡提示。
- 下载器与界面分离，可注入网络层以便测试。

### 7.4 缺少组件时的表现

- 没有语音模型：浮层状态显示“需要先下载语音识别模型”，点击打开下载界面；不再提示运行 `scripts/download_model.py`（源码开发仍可用该脚本）。
- 没有 llama.cpp 或改写模型：智能编辑状态显示“未安装”，旁边“去下载”按钮跳到下载列表；录音和输入照常可用。

### 7.5 llama.cpp 两个版本都提供（用户决定），并转存到我们的 Hugging Face 仓库

2026-10-18 在本机（RTX 3060 Laptop）用 v4 Q8、测试集 v4 实测（两者在相同条件下测，后台其他程序约占 2 GB 显存）：

| | 通用版（Vulkan） | NVIDIA 加速版（CUDA） |
| --- | --- | --- |
| 单句延迟中位数 | 0.150 s | 0.154 s |
| 字符错误率 / 反例保留 / 翻译 chrF | 0.202 / 95% / 65.0 | 0.198 / 95% / 64.8 |
| 服务占用显存 | 约 2.0 GB | 约 2.1 GB |
| 服务启动（连续 3 次） | 4.0 / 4.1 / 4.0 s；首次运行约 8 s（编译显卡着色器，之后有缓存） | 4.1 / 4.1 / 4.0 s |
| 下载 / 解压 | 30 MB / 88 MB | 625 MB / 1.2 GB |
| 支持的显卡 | NVIDIA / AMD / Intel | 仅 NVIDIA |

用户决定两个版本都放进下载列表，由用户选择，并注明效果：

- **通用版（Vulkan）· 推荐**：“30 MB · NVIDIA / AMD / Intel 显卡都能用 · 第一次启动稍慢（约 8 秒），之后与加速版相同”。
- **NVIDIA 加速版（CUDA）**：“625 MB · 仅 NVIDIA 显卡 · 实测速度与通用版相同，体积大 20 倍”。

两者装在同一位置，二选一：装其中一个时替换另一个（勾选框按单选处理）。检测不到 NVIDIA 显卡时，加速版显示“需要 NVIDIA 显卡”且不能勾选。

llama.cpp 官方只在 GitHub 发布，国内镜像对它无效，所以把 `llama-b11596-bin-win-vulkan-x64.zip`、`llama-b11596-bin-win-cuda-12.4-x64.zip` 和 `cudart-llama-bin-win-cuda-12.4-x64.zip` 原样上传到 `ThermalEX/voxflow-rewrite` 的 `runtime/` 目录（MIT 许可允许再分发，一并上传 LICENSE），与模型走同一个下载源。下载后只解压 llama-server 需要的文件（与 `packaging/build.py` 现有的筛选规则一致）。没有可用 Vulkan 显卡时 llama.cpp 会回退到 CPU，速度较慢但可用；设置页模型状态里提示即可。

### 7.6 卸载

卸载时询问“是否同时删除已下载的模型和组件（约 X GB）”，默认不删除，方便重装后直接使用。
